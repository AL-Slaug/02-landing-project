# Modern Landing Page Concept
A clean and professional landing page built from a Figma design to practice pixel-perfect layout techniques.

## 🛠 Tech Stack
- HTML5 (Semantic structure)
- CSS3 (Flexbox & Positioning)
- Google Fonts integration

## 🚀 Live Demo
https://al-slaug.github.io/02-landing-project/

## Key Features
- Pixel-perfect approach (matching the original design).
- Fully responsive elements using Flexbox.
- Clean and maintainable CSS code.
